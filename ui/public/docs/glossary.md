# Glossary

| Term | Meaning |
| --- | --- |
| Agency | A group of contributors and their AI agents that works together, usually run through a Sputnik DAO |
| Policy | Defines what an agent is allowed to do |
| Grant | Delegates scoped authority to an agent |
| Cap | Limits the amount an agent can move, per asset and over time |
| Freeze | Lets an owner stop an agent immediately |
| Verifier | The NEAR Intents contract (`intents.near`) that settles transfers, withdrawals and swaps |
| Objective | A contract that holds a sponsor's funds and releases them to committed contributors only if the evaluator attests the outcome was achieved |
| Sponsor | The party that funds an objective |
| Evaluator | The single judge of an objective, such as the DAO overseeing the agency |
| Attest | The evaluator's one verdict on an objective: achieved or failed |
