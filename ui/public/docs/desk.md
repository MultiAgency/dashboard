# Desk

Hosted at `desk.multiagency.ai`.

Desk turns signed job terms into a payment agent that can only pay what was agreed. This automates operational processes: the terms are agreed first, then payment follows them and nothing else.

Desk builds on the [Platform](/docs/platform), so the payment agent works inside a scoped grant and cap, and an owner can freeze it.
